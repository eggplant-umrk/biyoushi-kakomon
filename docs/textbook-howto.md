# 教科書の参照を付ける手順

問題の解説の下に「教科書 運営管理 第2版 第2編2章2節 p.64（第2版の場合）」のように、教科書のどこを開けばよいかを1行で出す仕組みの手順書です。
どの教科書も、同じ手順・同じ仕組みで扱います（仕様は SPEC §14-54・57）。

## やってはいけないこと（最初に読む）

教科書の奥付に「私的使用以外のいかなる電子的複製行為（コピー、スキャン、デジタル化）も一切認められておりません」とあります。

- **教科書の写真をコミットしない。** 写真は `textbook-src/<フォルダ>/` に置く（`.gitignore` 済み）。ほかの場所に置かない
- **本文、目次の全文、索引の全文を、リポジトリのどこにも書かない。** データ（`data-src/`・`public/`）、文書（`docs/`）、コード、テスト、コミットメッセージ、PRの説明のすべて
- リポジトリに入れてよいのは、**問題ごとの参照（その問題に関係する節の見出しとページ）だけ**
- 目次・索引を書き写した**一時ファイルは、リポジトリの外（一時フォルダ）に作り、作業が終わったら消す**。`textbook-src/` の中にも残さない
- 解説の文章に、教科書の文をそのまま写さない（SPEC §6.7.2）
- テストに実在の教科書の目次・索引を使わない（`scripts/textbook-refs.test.ts` は架空の教科書を使っている）

コミットの前に、下の「コミット前の確認」を必ず行ってください。

## 1. 後輩にお願いする写真

1冊につき、次のページをスマホで撮ってもらいます（全部で10枚前後）。本文は撮りません。

| 写真 | 何に使うか |
|---|---|
| 表紙 | 書名の確認 |
| 奥付（最後のページ。発行日・版・発行者が書いてある） | 版と発行年（`bookId`）、初版の発行日 |
| 目次（全ページ） | 節の見出しと開始ページ。ページから節を決める |
| 索引（全ページ） | 用語からページを引く |
| 参考図書・付録の一覧（あれば） | 本文の最後のページを確かめる |

撮り方のお願い：

- ページ番号が読めること（特に目次の右端の数字、索引の数字）。影や指がかからないように
- 1ページを1枚で、真上から。見開きを1枚に入れると数字が小さくなる
- 索引の最初のページは、ページ番号（本文が何ページで終わるかが分かる）も入るように
- 目次や索引がない教科書は、ある方だけでよい（下の「目次だけ・索引だけの教科書」）

## 2. フォルダの置き方

```
textbook-src/            ← .gitignore 済み。コミットしない
  unei/                  ← 教科書ごとのフォルダ（設定の photoDir と同じ名前）
    S__458334214.jpg …   ← 写真（ファイル名は何でもよい）
  eisei/                 ← 次の教科書
```

## 3. 設定を足す（`data-src/textbooks.json`）

教科書を足すときは、この設定に1件足すだけです。コードは変えません。

```json
{
  "bookId": "unei-2ed-2024",
  "title": "運営管理",
  "edition": "第2版",
  "year": 2024,
  "firstEditionDate": "2023-04-01",
  "publisher": "公益社団法人 日本理容美容教育センター",
  "photoDir": "unei",
  "fields": ["law"],
  "subject": "運営管理（…）"
}
```

- `bookId`：`<科目の短い名前>-<版>-<その版の発行年>`。版が変わったら別の `bookId` にする（ページがずれるため）
- `edition`・`year`：奥付の、いちばん新しい版と発行年。画面に「第2版の場合」と出る
- `firstEditionDate`：奥付の初版の発行日。これより前に実施された回の問題は、確信度を高にしない（下の注意点）
- `fields`：この教科書が対象にする分野（問題の `fieldId`。`law`＝問1〜10、`public_health`＝11〜15、`infection`＝16〜20、`hygiene`＝21〜25、`anatomy`＝26〜30、`skin`＝31〜35、`cosmetics`＝36〜40、`theory`＝41〜55）。ここにない分野の問題には付けられない（検証でエラー）
- 設定には、書名・版・発行者などだけを書く。**目次や本文は書かない**

1つの問題に複数の教科書の参照を付けられます（例：問1〜10 に『関係法規』と『運営管理』の両方）。`fields` が重なっていてかまいません。

## 4. 一時ファイルを作る（リポジトリの外）

写真を読んで、次の3つを**一時フォルダ**（例：`%TEMP%\tb-unei\`）に作ります。

`toc.json`（目次。節の見出しと開始ページ）

```json
{ "lastPage": 157,
  "sections": [
    { "chapter": "第1編 第1章", "section": "第1節", "title": "（節の見出し）", "start": 8 }
  ] }
```

- `lastPage`：本文の最後のページ（索引が p.158 から始まるなら 157）
- 節のない章は `section` を `""` にする。編・章だけの行（節の上の見出し）は書かない

`index.json`（索引。語とページ）

```json
{ "国民年金": [64, 66], "雇用保険": [59, 74] }
```

- 「→ ○○ 参照」の行は書かなくてよい。全部でなくても、対象の分野に関係しそうな語だけでよい

`plan.json`（割り当て。どの問題に、どの語・節を当てるか）

```json
{ "54-08": [{ "term": "国民年金" }],
  "54-10": [{ "term": "雇用保険", "page": 74 }],
  "52-09": [{ "term": "労働基準法", "confidence": "medium" }, { "term": "労働安全衛生法", "confidence": "medium" }],
  "43-08": [{ "section": "第1編 第3章/第5節" }],
  "53-07": "none" }
```

- `term`：索引の語。`page` を省くと、その語の最初のページ。語のページが複数の節にあるときは、主題に合う節のページを `page` で指定する
- `section`：索引に語がないとき、目次の節を `"章/節"` で書く（ページは節の開始ページ、確信度は low になる）
- `"none"`：調べたが、この教科書に対応する内容がない
- `confidence: "medium"`：高を中に下げる（下の「確信度の付け方」）

対象の問題の一覧は、次のコマンドで出せます。

```sh
node scripts/textbook-refs.ts targets unei-2ed-2024
```

## 5. 実行するコマンド

```sh
T="$TEMP/tb-unei"   # 一時フォルダ

# 参照を作る（その教科書の分だけを置き換える。ほかの教科書の参照は残る）
node scripts/textbook-refs.ts assign unei-2ed-2024 --plan "$T/plan.json" --toc "$T/toc.json" --index "$T/index.json"

# 確かめる（下の「検証」）
node scripts/textbook-refs.ts verify unei-2ed-2024 --plan "$T/plan.json" --toc "$T/toc.json" --index "$T/index.json"

# 問題データに反映して、全体を検証
node scripts/build-data.ts && node scripts/validate.ts --expect 41-54 && npm test

# 件数（教科書ごとの、参照あり・確信度の内訳・該当なし）
node scripts/textbook-refs.ts stats
```

`assign` は、エラーが1件でもあれば何も書き込みません。書き込む先は `data-src/textbook-refs.json`（`refs`＝問題ごとの参照、`none`＝教科書ごとの「該当なし」の問題）です。

## 6. 検証

`verify` に一時ファイルを渡すと、次を確かめます。

- 各参照のページが、その節のページ範囲（目次の開始ページ〜次の節の開始ページの前。最後の節は `lastPage` まで）に入っている
- 節の見出しが、目次と同じ
- 索引から引いた参照（`via: index`）のページが、索引に載っている。割り当てた語のページである
- 目次から推定した参照（`via: toc`）は、節の開始ページで、確信度が low
- 教科書の初版より前の回の参照が、高になっていない
- 対象の分野の問題である。参照と「該当なし」の両方に入っていない。同じ参照が2つない
- 目次・索引の書き写しの誤りらしいもの（開始ページが前の節より小さい、索引のページが本文の最後を超える、など）

一時ファイルなしの `node scripts/textbook-refs.ts verify` は、決まり（登録済みの教科書・分野・確信度）だけを確かめます。こちらは CI で毎回動きます。

人の目での確認：

- 別の人（または別のエージェント）に、写真と参照を見比べてもらう。運営管理の結果は `docs/review-textbook.md`
- 画面：`npm run dev` で、参照を付けた問題に解答し、解説の下に1行出ることを見る。E2E は `e2e/explanation.spec.ts`

## 7. 片づけと、コミット前の確認

```sh
rm -r "$T"                                   # 一時ファイルを消す
git status --short                           # textbook-src/ や一時ファイルが出てこないこと
git diff --cached --stat                     # 変わったのは textbooks.json・textbook-refs.json・public/data・文書だけ
git ls-files | grep -c "^textbook-src/"      # 0 であること
```

`data-src/textbook-refs.json` を開いて、入っているのが節の見出しとページだけであること（使っていない節の見出しや、索引の語の一覧が入っていないこと）を確かめます。

## 8. 目次だけ・索引だけの教科書

- **目次だけ**：`--toc` だけを渡す。割り当てはすべて `section` で書く。参照はすべて「目次からの推定・確信度 low・節の開始ページ」になる
- **索引だけ**：`--index` だけを渡す。割り当てはすべて `term` で書く。節は決められないので、参照は「索引の語とページ」だけになる（画面は「教科書 ○○ 第2版 p.68」と語を出す）。検証は、索引のページだけを確かめる
- 章だけで節のない教科書：`toc.json` の `section` を `""` にする（画面は「第3章 p.40」）
- 目次の形が違う（部・章・項など）：`chapter` に上の階層をまとめて書き（例：`"第2部 第3章"`）、`section` にいちばん下の階層を書く。表示は `chapter` と `section` をつないで短くするだけ

## 9. 『運営管理』で分かった注意点

### どの問題が対象か

- 『運営管理』が対象にする分野は「関係法規・制度及び運営管理」（問1〜10）だが、このうち美容師法・保健所・生衛法の問題は、別の教科書（『関係法規・制度』）の内容。『運営管理』の索引・目次に対応する語がないので、割り当てに入れない（「未確認」のままにする。『関係法規・制度』の教科書が届いたら、そちらで付ける）
- 「該当なし」（`"none"`）にするのは、**運営や労務に関係しそうに見えるが、この教科書に対応する内容がない**問題だけ（例：「美容業の運営に関連する法律」として医師法・個人情報保護法などを問う問題）
- 第41〜54回では、運営管理の問題は各回の問7〜10 あたりにあり、主題は労働基準法、労働安全衛生法、税金、会計、公的年金、医療保険、介護保険、雇用保険・労災保険に限られていた

### 索引の語の選び方

- **問題の主題そのものの語**を使う（「労働基準法に関する次の記述…」なら「労働基準法」）
- 主題の語が索引にないとき（例：「医療保険」「労働保険」という語は索引にない）は、**選択肢に出てくる語のうち、主題の節に入るもの**を使う（医療保険の問題 →「国民健康保険」。労働保険の問題 →「雇用保険」）
- 1つの語のページが複数の節にあるとき（例：「雇用保険」が労働者の権利の節と労働保険の節にある）は、**主題に合う見出しの節のページ**を `page` で指定する
- 索引にまったく語がない主題（例：消費税）は、目次の節から推定する（確信度 low）
- 問題が2つの主題にまたがるとき（例：労働基準法と労働安全衛生法、税金の種類と申告、公的年金と医療保険）は、**参照を2件**にする
- 選択肢の1つにだけ関係する語（例：生衛法の問題の選択肢に出る語が、この教科書の索引にある）は、付けるなら中にする

### 確信度の付け方

| 確信度 | 条件 |
|---|---|
| 高 | 索引の語が問題の主題で、そのページが、主題に合う見出しの節にある（語のページがほかの節にもあっても、主題の節が1つに決まるなら高でよい） |
| 中 | 索引の語はあるが、①節の見出しが主題そのものではない（例：介護保険が医療保険の節にある）、②問題が複数の主題にまたがる、③選択肢の一部にだけ関係する、④教科書の初版より前の回 |
| 低 | 索引に語がなく、目次から節を推定した |

### 古い回との対応

- 第41〜47回（2020年3月〜2023年3月）は、この教科書の初版（2023年4月1日）より前の出題。問題は当時の教科書に基づいているので、**主題が同じでも、高にしない**（道具が自動で中に下げる）
- 制度の問題は、主題（年金・医療保険・労働基準法など）が今の教科書にもあるので、参照は付けられた。内容が対応しない問題（当時の教科書にしかない話題）は、無理に付けず「該当なし」にする
- 教科書の本文は見ていないので、「そのページに、その選択肢の内容が書いてあるか」までは確かめていない。参照は「まずここを開く」という手がかりで、解説の根拠（`sources`）ではない

### 版について

- ページは版でずれることがある。`bookId` に版と発行年を入れ、画面に「第2版の場合」と添えている
- 新しい版が出たら、新しい `bookId` で登録し直し、写真をもらって同じ手順で付け直す（古い `bookId` の参照は、`assign` で新しい教科書の分を作ったあと、設定から古い教科書を消す前に `data-src/textbook-refs.json` から取り除く）
