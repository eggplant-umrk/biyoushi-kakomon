# デザインの方針

対象は美容学校の学生。ほとんどがスマホ（iPhone・Android）で、すきま時間に片手で使う。
**落ち着いていて信頼でき、古く感じない**見た目にする。派手な装飾はせず、「いま何をすればよいか」が一目で分かることを優先する。

操作の流れは、ほかの過去問アプリ（ITパスポート過去問道場、過去問ドットコム、美容師の過去問アプリ）の傾向を参考にした（文章・画像・配色は参考にしていない）。取り入れたのは次の流れ：
- 「続きから」を最上段に置き、押せばすぐ前回の問題に戻る
- よく使う出題（今日の10問・間違えた問題・弱い分野）は、ホームから1タップで始める
- 解答したらすぐ正誤を出し、解説は要点を先に、詳細は折りたたむ
- 次へ・前へは、下の大きなボタンとスワイプの両方でできる
- 「あとで見直す」（★）と「間違えた問題」は、別々に集めて解き直せる
- 成績は分野別を横棒グラフで、回別も同じ形で見せ、弱い分野から1タップで解ける

## 配色

1つの主な色（ベリー）と、正誤・注意の意味の色だけを使う。色は CSS 変数（`src/styles.css` の先頭）で管理し、画面ごとに色を書かない。

| 役割 | ライト | ダーク | 使う場所 |
|---|---|---|---|
| 背景 | `#f6f4f3` | `#141214` | 画面の地 |
| 面 | `#ffffff` | `#1f1b1e` | カード・選択肢 |
| 文字 | `#1d1a1c` | `#f1ecee` | 本文 |
| 補助の文字 | `#625a5e` | `#b4aaaf` | 説明・ラベル（背景とのコントラスト 4.5:1 以上） |
| 主な色 | `#9e3a64` | `#e48db1` | ボタン・選択中のタブ・進捗 |
| 正解 | `#1a7448` | `#63d39b` | ○・正答の選択肢 |
| 不正解 | `#b42e22` | `#ff8f80` | ×・選んだ誤りの選択肢 |
| 注意 | `#7d5200` | `#f0c35e` | 注意書き・確認中 |

- **色だけに頼らない**：正誤は必ず「色＋記号（○・×）＋文字（正解・不正解・正答・あなたの解答）」で出す。グラフにも数値を文字で添える
- ダークモードは、端末の設定に合わせるのが既定。設定の画面で、ライト・ダークに固定もできる

## 文字

- 端末の標準フォント（ヒラギノ、Noto Sans JP など）。Webフォントは読み込まない（速さのため）
- 本文 17px（設定で 19px・21px に変えられる）。行間 1.7
- 見出し：画面の見出し 1.35rem、カードの見出し 1.05rem、ラベル 0.82rem
- 文字サイズを大きくしても崩れないよう、幅は rem と %、高さは最小値（min-height）で決める

## 余白

- 4px を単位に、4・8・12・16・24・32px だけを使う
- 画面の左右は 16px（ノッチのある端末は安全領域に合わせる）
- カードの中は 16px、カードどうしは 12px

## ボタンとタップ領域

- タップできるものは、高さ 48px 以上（主なボタンは 52px、選択肢は 56px 以上）
- 主なボタン（塗り）は、1画面に1つ。ほかは枠線か文字だけのボタン
- 片手で届くよう、よく押すボタン（次へ・前へ・始める）は画面の下に固定する
- 押したときは、背景が少し濃くなり、ほんの少し沈む（`scale(0.98)`）

## 角丸と影

- カード 16px、ボタン 12px、チップ 999px（丸）
- 影はほぼ使わず、1px の線で区切る。下に固定するバーにだけ、薄い影を付ける

## アニメーション（控えめ）

- 押したときの反応、正誤の表示、折りたたみの開閉だけに使う。長さは 120〜200ms
- 問題の切り替えは、スワイプの向きに合わせて 160ms で横に少し動かす
- 端末で「視差効果を減らす」を選んでいる人には、動きを止める（`prefers-reduced-motion`）

## アイコン

- 線の太さをそろえた、自作の SVG アイコン（24px、線 1.8px、角は丸め）を `src/components/Icon.tsx` にまとめる。絵文字や記号の文字は使わない
- ナビゲーションでは、アイコンに必ず文字を添える
- 意味を持つアイコン（○・×・★）は、読み上げ用の文言も付ける

## 画面の構成

- **下のナビゲーション**：ホーム・解く・読む・記録・設定（管理者には管理）
- **ホーム**：最上段に「続きから」「今日やること」「弱点」。どれも1タップで解き始められる
- **解く**：出題条件。前回と同じ条件で解く人が多いので、最上段に「前回の条件で始める」を置き、細かい条件は下にまとめる
- **読む**：閲覧モードの入口（7a-2 で実装。今は準備中の案内だけ）
- **解答画面**：上に進捗、真ん中に問題と選択肢、下に「前へ」「次へ」。左右のスワイプでも前後に移れる
- **記録**：分野別・回別の正答率を横棒グラフ、直近14日の解答数を縦棒グラフで

## 7a-2 に向けた土台

- 閲覧モード（読む）：`/read` の画面とナビゲーションの入口を用意した
- 検索・要復習マーク・メモ：解答画面の上の段（★の隣）と、問題の見出しの行に、ボタンを足せる余白を空けてある
- 図の拡大：図の拡大表示を部品（`FigureViewer`）にしたので、閲覧モードでもそのまま使える
